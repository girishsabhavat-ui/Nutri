    System Engineering & Modular Design

    6-Module Survey Application Architecture

    1. Onboarding & Auth FSM

    5s timed splash (setInterval) transitions to institutional login with required Name + Consent gate.

    2. Question & Logic Engine

    4-domain state machine tracks completion, enforces answer validation, and prevents forward-skipping.

    3. Instant Feedback Layer

    Conditional DOM reveal keeps jokes hidden until selection, preventing response bias.

    4. Weighted Scoring Engine

    Computes 120-point composite score, 4 domain sub-scores, and maps thresholds to 5 personas.

    5. Audit Trail Persistence

    Fault-tolerant localStorage JSON store with unique Audit IDs and in-memory fallback.

    6. Analytics & Export

    Real-time Chart.js aggregation + RFC 4180 CSV and JSON Blob exporters.
